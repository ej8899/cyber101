## Infrastructure & Homelab

Calling it a *homelab* is becoming increasingly inaccurate.

What started as a collection of servers used for experimentation has grown into a distributed infrastructure environment approaching **1 PB of total storage capacity**.

A significant portion of the environment now consists of **production systems supporting clients across Canada**.

The environment includes:

* Production web servers
* Linux application servers
* VPS infrastructure
* Backup and disaster recovery systems
* Virtualization clusters
* NAS and large-scale storage systems
* Database servers
* API services
* Monitoring and telemetry systems
* Security monitoring infrastructure
* Development and test environments
* Containerized services
* Reverse proxies and secure tunnels
* Private networking between locations
* Automated backup and replication
* Cloud-integrated infrastructure

Platforms and technologies include combinations of:

`Linux` · `Windows Server` · `Proxmox` · `Docker` · `Synology` · `AWS` · `Cloudflare` · `Microsoft 365` · `PostgreSQL` · `MySQL` · `SQLite` · `Nginx` · `Node.js` · `PHP` · `Python` · `Go`

The environment is used both as a production platform and as a place to test new architectures, monitoring strategies, automation and security controls before deploying them elsewhere.
